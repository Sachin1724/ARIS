# ARIS Full App Specification

Locked stack: React Native + Expo + TypeScript, Expo Router, gluestack-ui, NativeWind, Poppins headings and Inter body text. The Arduino UNO Q hosts FastAPI, SQLite, sensor processing, LSTM forecasting, deterministic recommendations and optional local SLM. BLE is for discovery/secure Wi-Fi provisioning; existing Wi-Fi is used for REST and WebSocket communication.
