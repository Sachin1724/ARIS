# Release Checklist

- [ ] Poppins/Inter load on target platforms.
- [ ] Mascot assets/states consistent; reduced-motion supported.
- [ ] All screens have loading/empty/stale/disconnected/error states.
- [ ] Demo data visibly marked and disabled in production.
- [ ] BLE identity and secure provisioning tested.
- [ ] API verified over Wi-Fi before showing Connected.
- [ ] REST/WebSocket auth consistent; discovery fallback works.
- [ ] Reconnect after DHCP/network/device restart works.
- [ ] Forecast readiness and calibration states accurate.
- [ ] No secrets in source, bundle or logs.
- [ ] Provider keys remain on UNO Q.
- [ ] No raw audio/image upload without explicit opt-in.
- [ ] Target-device, accessibility, keyboard and performance checks pass.
