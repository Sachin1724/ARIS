# Architecture Decisions

- React Native + Expo + TypeScript: accepted; BLE likely requires development build/native module.
- gluestack-ui + NativeWind: accepted plan; pin compatible versions.
- UNO Q hosts initial backend: accepted; no cloud required for single-device first release.
- BLE setup, existing Wi-Fi runtime: accepted design; verify hardware/software behavior.
- REST + WebSocket: proposed protocol; align to actual backend.
- Deterministic rules + SLM phrasing: accepted; SLM does not invent values or thresholds.
- Mascot-led lavender theme, Poppins headings, Inter body: accepted.
