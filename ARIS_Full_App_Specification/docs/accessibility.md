# Accessibility

- Meaningful screen-reader labels and logical focus order.
- Touch targets around 44–48 dp where feasible.
- Support text scaling without clipping.
- Never use color alone for status.
- Charts need accessible labels and textual summaries.
- Microphone has visible listening/permission/error states.
- Respect reduced motion.
- Always retain typed input and visible text answers.
- Check contrast on actual pastel surfaces.
- Error messages state both problem and next action.
- Do not steal focus for every live sensor update.
