# Screen Specifications

## Home
Greeting, connection state, mascot, primary air-quality status, compact sensor row, trend preview, one recommendation with “Why?” and Ask ARIS CTA. Support loading/demo/connected/stale/disconnected/uncalibrated/forecast-not-ready states.

## Air Quality
Selected metric, unit, timestamp, validity, category source, chart, explanation, calibration note. Never guarantee air is “safe”.

## Trends
Metric/time-range selectors, observed history, visually separate predicted points, forecast horizon, model readiness, timestamps and gaps.

## Explore
Weather, wind, rain, humidity and optional traffic. Show source and last-updated time; explain correlation is not proof of pollution cause.

## Ask ARIS
Conversation, typed input, optional mic, transcript, answer, evidence/reasons and audio playback state.

## Connect UNO Q
Intro, BLE scan, device ID, pairing, Wi-Fi selection/password, progress steps, API verification, success, diagnostics and retry. Never show credentials in logs.

## Profile/settings
Device management, units, language/voice, notifications, privacy, permissions and data/cache preferences.
